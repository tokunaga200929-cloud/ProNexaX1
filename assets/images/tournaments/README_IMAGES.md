# Tournament / venue card images

SIDE STEP A-3で参照できるカード背景画像置き場です。

CMSまたは大会データに以下のどれかが入っていると、試合検索カード左側の背景画像として使えます。

```txt
imageUrl
cardImageUrl
coverImageUrl
venueImageUrl
courseImageUrl
backgroundImageUrl
```

例:

```txt
assets/images/tournaments/fuji-ichihara.jpg
assets/images/tournaments/minami-mobara.jpg
```

このSTEPでは画像本体は同梱していません。
