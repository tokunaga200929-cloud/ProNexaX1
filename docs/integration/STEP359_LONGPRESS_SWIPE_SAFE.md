# STEP359 長押し気味の月スワイプ改善

## 内容
Googleカレンダーのように、長押し気味に触って横へ動かした時も月スワイプとして反応しやすくした。

## 安全設計
- 予定チップ上では従来通り予定ドラッグ/詳細操作を優先
- 空白セル上だけ、横移動が強い場合に月スワイプを優先
- すでに範囲選択が始まっている場合は邪魔しない
- 横移動を検知したら、待機中の長押し範囲選択タイマーだけキャンセル

## 変更
- monthSwipe に horizontalLock を追加
- 横移動 18px 以上かつ横優位なら月スワイプ優先
- pending rangeSelect だけキャンセル
- touch-action を月グリッド向けに調整
