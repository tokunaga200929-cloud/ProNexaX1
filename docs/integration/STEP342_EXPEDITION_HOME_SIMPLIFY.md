# STEP342 遠征トップ簡略化

## 内容
遠征トップから「準備状況」カードを外し、トップ画面をシンプルに整理。

## 方針
- 遠征トップ：入口画面
  - 次の遠征
  - 保存済みの遠征
- 遠征詳細：管理画面
  - ホテル
  - 移動
  - 費用
  - 持ち物
  - 領収書
  - 準備状況

## 変更点
- ホーム画面では準備状況カードを非表示
- 次の遠征カードと保存済み遠征一覧を見やすく調整
- 準備中チップの見切れ対策を維持
- renderPreparationStatus 関数は今後の詳細画面再利用用に残す

## 注意
機能データは削除していません。ホームで表示しないだけです。
