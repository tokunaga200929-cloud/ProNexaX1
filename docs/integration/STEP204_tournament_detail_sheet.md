# STEP204 大会詳細Bottom Sheet強化

## 実装内容
- STEP203の `pronexax_step203_with_new_app_icon.zip` を基準に継続。
- 試合検索から追加された大会予定を、通常予定とは別の「大会の詳細」として表示。
- 大会名、開催日、会場、主催、賞金、エントリー締切、エントリー費、カテゴリ、状態、補足をBottom Sheetで確認可能。
- 大会予定では通常予定の編集ボタンを非表示にし、削除操作だけ安全に残す。
- 月間カレンダー上の大会チップをタップしても詳細Bottom Sheetが開くように調整。
- 終日大会は詳細で `00:00〜00:00` ではなく `終日` と表示。

## 触っていないこと
- 試合検索モジュールのデザイン・データ構造は変更なし。
- 収支、注目、マイページ、CMS連携は未変更。
- 既存のカレンダー削除・追加・月移動・下部ナビは維持。
