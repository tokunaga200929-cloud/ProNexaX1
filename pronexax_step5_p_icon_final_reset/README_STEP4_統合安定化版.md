# STEP4 ProNexaX 統合安定化版

このZIPは、STEP3で表示成功した状態をベースに、下記を安定化した版です。

## 接続済み

- カレンダー本体
- 試合検索
- 収支
- 注目/広告（中央P）

## 安定化した内容

- `page-search / page-finance / page-featured` の高さを統一
- iframe の `height:100% / flex:1` を強制
- 本体下部ナビが常に表示されるよう z-index 調整
- モジュール側の単独下部ナビを非表示
- iframe読み込み時の白チラつきを軽減
- 横スクロールや余白崩れを防止

## 開くファイル

```txt
index.html
```

## 確認順

1. カレンダー表示
2. 試合検索表示
3. 収支表示
4. 中央P 注目/広告表示
5. それぞれからカレンダーに戻れる
6. 下部ナビが二重表示されていない
7. 画面下に大きな余白が出ていない

## 次のSTEP候補

- 大会検索 → カレンダー追加の本格連携
- 大会 → 収支の紐付け
- CMSを `/cms` として本格運用
- Firebase / Firestore 接続
