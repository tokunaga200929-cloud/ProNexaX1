# STEP1 試合検索接続版

このZIPは、ProNexaX本体に「試合検索だけ」を接続した版です。

## 開くファイル

```txt
index.html
```

## 今回やったこと

- 本体 `#page-search` の空枠を置き換え
- `pages/search/embed.html` を作成
- 本体下部ナビの「試合検索」を押すと、試合検索モジュールが表示される
- 試合検索側の単独下部ナビ `#tab-bar` は非表示
- カレンダー本体のHTML/JSは極力触らず維持

## まだやっていないこと

- 収支の本体接続
- 注目/広告の本体接続
- 本体カレンダーとの大会データ連携
- CMS連携

## 注意

今回は安全優先で iframe 接続にしています。
レイアウト確認後、問題なければ次のSTEPで収支も同じ方式で接続できます。
