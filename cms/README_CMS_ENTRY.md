# ProNexaX CMS 本番入口

このフォルダはSTEP73から、最終Apple風CMSの入口です。

## 開くファイル

```txt
cms/index.html
```

## 重要

旧CMSは削除していません。

```txt
cms-legacy/
```

に退避しています。

## 現在のCMS機能

- PICK UP / 注目ページ管理
- Claude Console前提のAI一括大会登録
- 登録済み大会管理
- 公開前チェック / 重複チェック
- 本体試合検索反映チェック
- 右側iPhoneライブプレビュー実データ連動
- 保存状態確認 / バックアップ / 復元
- メディアライブラリ
- メディア素材の紐づけ
